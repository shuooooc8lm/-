# 🎲 吃啥? - 北醫吃飯選擇障礙小幫手

這是一個專為解決校園周邊用餐選擇障礙所開發的輕量級 PWA 網頁應用程式。無須下載 App、無後端資料庫，所有口袋名單與偏好設定皆安全儲存於您的設備瀏覽器中。

## ✨ 核心功能
- **智慧時間過濾**：自動比對當前時間，排除休息中或公休的店家。
- **多維度篩選**：可依據「食物分類」、「步行距離」、「預算級別」進行精準過濾。
- **抽籤轉盤**：順滑的抽籤動畫與震動回饋，隨機選出最佳推薦。
- **自訂口袋名單**：自由新增、刪除專屬您的美食清單，支援 JSON 格式匯出與匯入。
- **PWA 支援**：可直接加入手機主畫面，享受全螢幕、無網址列的原生 App 體驗。

### [v1.1] - 2026-10-05
**新增 (Added)**
- **我的收藏系統**：可在管理清單中將特定店家加入「收藏」，並於首頁開啟「僅從『我的收藏』中抽取」進行專屬過濾。
- **智慧搜尋列**：管理口袋名單介面新增搜尋框，可即時過濾店名或分類。
- **自動分類排序**：口袋名單現在會自動依照「分類」與「加入時間」進行群組化排序，提升閱讀性。

**修復與優化 (Fixed & Changed)**
- 修復 iOS 設備透過 Safari 加入主畫面後，頂部狀態列 (`safe-area-inset-top`) 內容重疊且異常模糊的問題。
- 營業時間輸入框改用原生 `<input type="time">` 搭配 5 分鐘級距，避免手動輸入格式錯誤。
- 優化長清單滾動體驗，增加頂部與底部的邊緣透明漸層遮罩 (Scroll Masking)。

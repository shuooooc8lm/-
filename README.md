# 🎲 吃啥? - 北醫吃飯選擇障礙小幫手

這是一個專為解決校園周邊用餐選擇障礙所開發的輕量級 PWA 網頁應用程式。無須下載 App、無後端資料庫，所有口袋名單與偏好設定皆安全儲存於您的設備瀏覽器中。

## ✨ 核心功能
- **智慧時間過濾**：自動比對當前時間，排除休息中或公休的店家。
- **多維度篩選**：可依據「食物分類」、「步行距離」、「預算級別」進行精準過濾。
- **抽籤轉盤**：順滑的抽籤動畫與震動回饋，隨機選出最佳推薦。
- **自訂口袋名單**：自由新增、刪除專屬您的美食清單，支援 JSON 格式匯出與匯入。
- **PWA 支援**：推薦加入手機主畫面，享受全螢幕、無網址列的原生 App 體驗。

## 📝 更新日誌 (Changelog)

### [v1.1.3] - 2026-10-05
**修復與優化 (Fixed & Changed)**
- 🔧 **時間選單重構**：全面改用原生的 `<select>` 下拉選單，徹底解決 iOS Safari 無法以 5 分鐘為單位選擇營業時間的系統限制。
- 📱 **iOS 沉浸體驗優化**：加入 `.ios-safe-top-guard` 實體背景防護色塊，解決 iOS PWA 模式下頁面滾動時頂部狀態列產生的模糊疊影問題。
- 🐛 **動畫穩定性**：修復抽籤轉盤動畫過程中的變數錯字 Bug，確保分類標籤正常渲染且程式穩定運行。

### [v1.1.0] - 2026-10-05
**新增 (Added)**
- 🌟 **我的收藏系統**：可在管理清單中點擊星星將特定店家加入「收藏」，首頁亦新增「僅從『我的收藏』中抽取」的專屬過濾開關。
- 🔍 **智慧搜尋列**：管理口袋名單介面新增搜尋框，可即時過濾店名或分類，加速查找效率。
- 📋 **自動分類排序**：口袋名單總覽現在會自動依照「分類」與「加入時間」進行群組化排序，提升閱讀與管理體驗。

**修復與優化 (Fixed & Changed)**
- 🎨 **視覺優化**：優化長清單滾動體驗，增加頂部與底部的邊緣透明漸層遮罩 (Scroll Masking)。
- ⚡ **防呆機制**：以自訂確認彈窗 (Modal) 取代原生 `confirm()`，避免誤刪資料並提升整體 UI 一致性。
- 🔔 **提示系統**：導入自訂 Toast 輕量滑出提示，取代原生的 `alert()` 視窗。

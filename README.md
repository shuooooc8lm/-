# 🎲 吃啥? - 北醫吃飯選擇障礙小幫手

這是一個專為解決校園周邊用餐選擇障礙所開發的輕量級 PWA 網頁應用程式。無須下載 App、無後端資料庫，所有口袋名單與偏好設定皆安全儲存於您的設備瀏覽器中。

## ✨ 核心功能
- **智慧時間過濾**：自動比對當前時間，排除休息中或公休的店家。
- **多維度篩選**：可依據「食物分類」、「步行距離」、「預算級別」進行精準過濾。
- **抽籤轉盤**：順滑的抽籤動畫與震動回饋，隨機選出最佳推薦。
- **自訂口袋名單**：自由新增、刪除專屬您的美食清單，支援 JSON 格式匯出與匯入。
- **PWA 支援**：推薦加入手機主畫面，享受全螢幕、無網址列的原生 App 體驗。

## 📝 更新日誌

### [v1.1.6] - 2026-10-06 (重大體驗升級版)
**🌟 新功能與底層升級 (New & Core Updates)**
- **結果頁快捷收藏**：抽籤結果卡片右上角新增大顆「⭐ 收藏」按鈕，看到喜歡的結果可直接加入收藏，並即時連動下方清單。
- **資料無痛升級與版本化**：LocalStorage 資料結構正式導入 `Version: 1` 機制，系統會自動將舊版資料轉移為新架構，為未來擴增「地址導航」等功能鋪路。
- **JSON 嚴格防呆驗證**：實作 `validateRestaurant` 檢查機制，當匯入無效或缺漏欄位的 JSON 檔案時，系統會精準攔截並提示，徹底防止網頁崩潰白屏。

**💎 介面與體驗優化 (UX / UI Tweaks)**
- **介面層級重組**：將原本冗長的設定區塊洗牌，保留「📋 我的店家」作為常駐列表專注於檢視，並將「新增店家 / 匯入匯出」移至底部並預設收合。
- **文案與 Emoji 直覺化**：
  - 距離定義消除模糊空間：改為 `附近就好 🚶`、`走一段路 🏃`、`都可以 🚌`。
  - 預算選擇加入數字提示：`＄ ≤150`、`＄＄ 151-300`、`＄＄＄ 300+`。
  - 開關文案精簡：改為 `排除休息中的店家`。
- **視覺降噪與重排**：將所有食物分類標籤 (Badge) 的底色飽和度降低，使視覺焦點能回歸「店名」；分類排列邏輯調整為符合真實情境的「飯、麵、其他正餐 → 點心飲料 → 宵夜」。
- **時間選單重構**：全面改用原生的 `<select>` 下拉選單，徹底解決 iOS 系統無法以 5 分鐘為單位選擇營業時間的原生限制。

### [v1.1.3] - 2026-10-05
**修復與優化 (Fixed & Changed)**
- 🔧 **時間選單重構**：全面改用原生的 `<select>` 下拉選單，徹底解決 iOS Safari 無法以 5 分鐘為單位選擇營業時間的系統限制。

### [v1.1.0] - 2026-10-05
**新增 (Added)**
- 🌟 **我的收藏系統**：可在管理清單中點擊星星將特定店家加入「收藏」，首頁亦新增「僅從『我的收藏』中抽取」的專屬過濾開關。
- 🔍 **智慧搜尋列**：管理口袋名單介面新增搜尋框，可即時過濾店名或分類，加速查找效率。
- 📋 **自動分類排序**：口袋名單總覽現在會自動依照「分類」與「加入時間」進行群組化排序，提升閱讀與管理體驗。

**修復與優化 (Fixed & Changed)**
- 🎨 **視覺優化**：優化長清單滾動體驗，增加頂部與底部的邊緣透明漸層遮罩 (Scroll Masking)。
- ⚡ **防呆機制**：以自訂確認彈窗 (Modal) 取代原生 `confirm()`，避免誤刪資料並提升整體 UI 一致性。
- 🔔 **提示系統**：導入自訂 Toast 輕量滑出提示，取代原生的 `alert()` 視窗。
